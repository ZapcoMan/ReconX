前端资产与授权侦察工作台

把被动采集与指纹分析、主动探测与客户端路由接管核验、OSINT 查询生成三条能力线，整合为一份采集结果与一套导出。

从 Release 下载 源码仓库 当前版本 v1.0.0 · GPL v2
使用前请先确认这几点。 它不是只读工具：主动探测会向目标发出真实请求，接管功能会修改目标页面的前端路由运行时状态。 接管只发生在客户端，服务端的 401/403 与数据级鉴权照样拦得住。 所有命中都是启发式线索，已对常见误报做降噪，但仍须人工确认后再据此提交漏洞。 命中与导出按原文留存（含密钥、Cookie 与响应头原值），采集历史也留在本机且不外传，但导出文件请谨慎分享；不需要时用设置页「采集历史」逐条删除或清空。 自 1.0.0 起工具不再用允许域限制技术作用范围，是否合规完全由使用者负责——请仅在你拥有或已获书面授权的资产上使用。

三条能力线

被动采集与指纹分析

技术栈 / WAF / 版本识别，响应头与 Cookie 安全分析，JS 敏感信息扫描，链接、端点与参数归集，Wappalyzer 式多信号技术栈合并。

页面侧路由探测脚本经逐函数核验为纯只读

主动探测与接管核验

敏感路径与已枚举路由的 HTTP 可达性核验；「梭哈模式」在页面主世界屏蔽前端守卫、改写鉴权 meta、拦截跳转，用于核验受保护前端路由能否直达。

会产生真实请求并改写页面运行时

OSINT 查询生成

Dork 语法库与资产测绘查询矩阵。只生成查询语法与检索地址文本供你复制，不会自动打开标签页、不会发生任何跳转。

零跳转

双源探测 · 不一致时不替你取舍

框架与路由各走两条独立采集路径，同一站点常会给出不同结论。ReconX 不静默择一，而是并列呈现、写明主次，把判断权交回你手里。

功能清单

采集与分析

  • 框架 / CMS / CDN / 边缘防护与版本线索识别
  • 安全头缺失、CSP 指令、CORS、Set-Cookie（HttpOnly / Secure / SameSite）风险
  • 响应头缓存约 30 分钟自动过期、主机数设上限，避免无限增长与陈旧头误导审计
  • 云密钥、Token、私钥、JWT、内网与元数据地址、Sourcemap、Git 痕迹扫描，命中一律原文留存（不掩码，导出即取证材料）；密钥正则与敏感路径探测均可追加自定义条目
  • DOM 链接、表单与隐藏字段、iframe、运行时资源、内联 /api 端点，按主机与参数归一去重
  • URL 规范化：跳转还原、去跟踪参数、域名 / 通配 / 正则黑名单（设置页每行一条自定）
  • 端点三级敏感分级（critical / warn / info）并排序
  • favicon 指纹（纯 JS MD5）用于同站 / 换皮识别与测绘比对
  • 从 JS 静态推断后端基址：axios baseURL、构建期 env（VITE_/VUE_APP_/REACT_APP_/NEXT_PUBLIC_）与代码内完整 origin，并标注是否跨域

前端与输出

  • 识别 Vue（Router 2/3/4）与 React（React Router / TanStack / Next.js）并枚举全部路由，按 Hash / History / base 生成可点击的完整 URL
  • API 端点三源提取：实际调用 + JS 源码静态正则 + Sourcemap 探测，标注未被调用的端点
  • 前端安全审计：敏感 API、未保护路由线索、Sourcemap 泄露 → 风险评级与修复建议。判定已降噪——路径关键词整词匹配、登录/协议/回跳等公开页不计入风险、路由权限看 meta 真值，普通 SPA 不再被整片标成风险
  • 多格式导出：JSON / CSV / Markdown / HTML / SRC 提交草稿 / 端点 TXT（可直接贴 Burp），可按风险等级过滤后导出，也可出综合报告或聚合多份既往结果
  • 每次采集自动留存，最近 20 份完整结果在设置页「采集历史」里逐份打开、删除或清空
  • 置信度分级：按严重度 / 来源佐证 / 探测响应状态给每条命中一个高 / 中 / 低 / 存疑档位，只影响阅读优先级、不移除原始命中
  • 复核工作清单：把 JS 发现 / 敏感接口 / 探测命中汇成按置信降序的待复核清单，可档位过滤、逐条标记误报，导出报告自带前 15 条复核优先级
  • 误报反哺：同一规则在多个站点被你判误报时提示"疑似过报"，可一键全站忽略——只提示、不自动改内置规则、不跨站隐藏真漏洞
  • 误报反馈闭环：结果页可逐条标记误报（默认只对本站点生效），命中移出展示但原始数据保留，设置页集中撤销 / 升为全站 / 清空
  • 两次采集对比：选一份历史作基线，逐类目看新增与消失（路径类按 path、JS 发现按规则 id），跨主机只做并列不误判
  • 结果页长表分页（10 / 50 / 100 / 500 每页），数据全量保留
  • 暗色 / 亮色 / 极客 / 跟随系统四档主题，联动 Element Plus 配色并持久化；跟随态下系统换明暗会实时跟上

安装与使用

  1. 下载从 GitHub Release 下载扩展包并解压（解压后的目录即 dist/）。
  2. 加载打开 chrome://extensions，开启右上角「开发者模式」，点「加载已解压的扩展程序」选择该目录。需 Chrome 111+。
  3. 采集打开目标站点，点扩展图标 →「开始采集」（1.0.0 起不再要求逐站点授权，是否使用由你自行负责）。
  4. 查看点「查看结果」分栏浏览，或选择导出格式。
  5. 探测（可选）先在设置页开启「启用主动探测」，再点「主动探测」执行敏感路径与路由可达性核验；判定为 Vue/React 时附带前端路由接管。

自行构建：npm install && npm run build，产物在 dist/。

注意：开启「启用主动探测」后，接管脚本会随任意站点每次页面加载自动生效，不再需要逐次点击「主动探测」；不需要时关闭该总开关即停止注入。工具不再用允许域限制作用范围，请仅对你拥有或已获书面授权的资产使用。
