# 功能与模块说明

ReconX 各能力模块、导出方式与代码结构的详细说明（README 仅保留门面，细节集中于此）。

## 功能矩阵

| 模块 | 能力 |
|---|---|
| 技术栈 / WAF / 版本指纹 | 从 Server、X-Powered-By、meta generator、Cookie、资源 URL、`window` 全局、HTML 特征识别框架/CMS/CDN/WAF 与版本线索 |
| Wappalyzer 式技术栈合并 | 交叉 HTTP 头/cookie/meta/资源URL/HTML/window 全局/路由结构，输出带**置信度**的技术栈清单，并据此判定站点是否为 Vue/React SPA（合并自被动指纹 + King-CrackX 框架检测） |
| 响应头与 Cookie 分析 | 安全头缺失/弱配置、CSP 指令、CORS、`Set-Cookie` 属性（HttpOnly/Secure/SameSite）、缓存与凭据风险 |
| JS 敏感信息扫描 | 外链/内联 JS 中的云密钥、Token、私钥、JWT、内网/元数据地址、source map、Git 痕迹（命中默认掩码） |
| 链接 / 端点 / 参数收集 | DOM 链接、表单与隐藏字段、iframe、运行时资源、内联 `/api` 端点，按主机/参数归一去重 |
| URL 规范化与敏感分级 | 跳转还原、去跟踪参数、域名/通配/正则黑名单；端点按 critical/warn/info 三级排序 |
| 前端路由枚举与完整 URL | 只读识别 Vue（Vue Router 2/3/4）与 React（React Router/Next.js）并枚举全部路由 → 按 Hash/History/base 拼出可点击的完整 URL；无法枚举时回落页面锚点 |
| API 端点提取 | 实际调用 + JS 源码静态正则 + Sourcemap 探测，标注未调用端点（可直接作为 Burp 目标） |
| 前端安全审计 | 敏感 API、未保护路由线索、Sourcemap 泄露 → 风险评级与修复建议，统一并入 bundle 与导出 |
| 资产测绘 / Dork 查询生成 | 生成 Fofa/Quake/Hunter/ZoomEye 与搜索引擎查询语句（**仅生成查询，不自动开标签**） |
| 主动探测（默认关闭） | 敏感路径 GET 探测；并对判定为 Vue/React 的站点追加前端路由 HTTP 可达性探测（不接管 Router、不绕过服务端鉴权） |
| 范围管控 / 导出 | 允许域白名单 + 逐目标 host 授权；多格式统一导出 |

## 导出

统一导出在扩展页面内用 `<a download>` 触发（**不依赖 `chrome.downloads`**，从根源避免了旧版 MV3 service worker blob 下载失效的问题）。格式：

- **JSON**：完整结构化结果
- **CSV**：发现项 / 技术栈 / WAF / 端点 / 路由 多维
- **Markdown**：人类可读报告
- **HTML**：自包含样式报告，可直接打开/打印转 PDF
- **SRC 报告**：面向漏洞赏金提交的草稿骨架（等级/位置/证据/复现/影响/建议）
- **端点 TXT**：URL 列表，可直接粘贴 Burp

并支持：**按等级筛选**、**多目标聚合导出**、**规则/Dork 库 JSON 导入导出**。实现在 `src/core/exporter.ts`（弹窗/详情页调用）。

## 目录结构

> 架构已重构为 **Vue 3 + TypeScript + Vite + @crxjs/vite-plugin + Element Plus + Pinia**。源码在 `src/`，`npm run build` 产出 `dist/`。

```
package.json / vite.config.ts / tsconfig*.json   构建配置；manifest 由 vite.config 内 defineManifest 生成
public/icons/                                     图标资源（构建时拷入 dist）
src/background.ts          ES module service worker：范围/采集/探测/技术栈决策编排
src/core/*.ts              只读分析规则库与探测：fingerprints / sensitive-rules / header-checks / url-classify / route-urls / api-extract / security-audit / tech-stack / probe-routes / collect-extras / asset-search / dork-library / exporter / router-probe
src/types/index.ts         跨模块共享类型（RouterProbeResult/Scope/Settings/TechItem/ReconBundle 等）
src/shared/messaging.ts    与 background 的 Promise 化消息封装
src/stores/app.ts          Pinia 共享状态：scope / settings / active tab / lastBundle / 采集与探测动作
src/popup/                 Vue SFC：授权 + 触发采集/探测/导出下拉/设置入口
src/result/                Vue SFC：分栏展示（概览/技术栈/路由/API/安全/主动探测/Dork与测绘/原始JSON）+ 复制/链接
src/options/               Vue SFC：允许域管理 / 采集参数 / 权限撤销 / 合规声明
docs/                      中文深度文档（本目录）
gen-icons.js               图标生成脚本（Node 内置模块，无依赖）
dist/                      构建产物；在 chrome://extensions 加载此目录
```

> 说明：旧版 `content-dom.js` 文件注入已取消，DOM 采集改由 `background.ts` 用 `chrome.scripting.executeScript({ func })` 直接返回 payload，因此不再有独立 content 脚本，`web_accessible_resources` 也不再需要注入脚本。

## 重新生成图标

```bash
node gen-icons.js
```

仅使用 Node 内置模块（`fs`/`path`/`zlib`），无第三方依赖。
