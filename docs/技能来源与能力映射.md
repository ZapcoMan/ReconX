# 技能来源与能力映射

本文档记录 ReconX 的功能来源与边界：它由哪些安全技能（skill）映射而来、哪些技能无法在浏览器扩展中落地、复用了哪些既有插件、以及当前的移植进度。README 只讲"怎么用"，本文讲"从哪来、能做到什么、不能做什么"。

## 一、来源技能 → 扩展能力映射

ReconX 最初按"信息收集"方向构建，关联的安全技能与落地情况如下：

| 技能 | 在扩展中的落地情况 | 说明 |
|---|---|---|
| **recon**（侦察/信息收集） | ✅ 完整落地 | 链接与端点/参数收集、技术栈/WAF/版本指纹、响应头与 Cookie 分析、JS 敏感信息扫描、资产测绘查询生成、Dork 查询生成。 |
| **web-architectural**（Web 架构层） | ✅ 部分落地 | 取其"指纹识别 / 被动信息收集"子集（Server、generator、Cookie、资源 URL、HTML 特征、WAF 特征）；并含**客户端路由接管**（梭哈模式，见下）。主动攻击类（LFI/反序列化/请求走私等）不属侦察范畴，不在本工具内。 |
| **binary-exploitation** | ❌ 不落地 | 内存破坏/ROP/堆利用属本地进程与内核层能力，浏览器扩展沙箱无法实现，也不应伪装成攻击面板。 |
| **wireless** | ❌ 不落地 | 802.11/蓝牙/亚 GHz 监听与破解需无线网卡与外部工具链，与扩展无关。 |
| **crypto** | ❌ 不落地 | 离线密码学破解（padding oracle/RSA 攻击等）作用于已捕获数据，不在浏览器内执行。扩展只做"密钥/令牌**泄露检测**"，不做破解。 |

> 设计原则：只做"收集、线索发现与授权范围内的可达性核验"，命中一律标注为**线索**，需人工确认；破解、内存利用、无线攻击不在工具职责内。

## 二、复用的两个插件及其贡献

ReconX 整合了以下两个既有 Chrome 扩展的功能面：

### 1. King-CrackX / King-Crack — 前端 SPA 侦察与接管
- 框架/版本检测（Vue 2/3、React 17/18/19）与**路由枚举 + 完整 URL 生成**（Vue Router / React Router / TanStack / Next.js）。
- **API 端点提取**：真实请求 + JS 源码静态提取 + Sourcemap 探测。
- **前端安全审计**：敏感 API、裸露/未授权路由、Sourcemap 泄露 → 风险评级与修复建议。
- **导出**：TXT（端点，可直接贴 Burp）/ JSON / Markdown 综合报告；下载采用页面内 `<a download>`（ReconX 导出实现即参考此方式）。
- **梭哈模式（已落地）**：`src/core/all-in.ts` → 构建为 `all-in.js`，在页面 MAIN world 屏蔽守卫注册、清空存量守卫容器、改写鉴权 meta、拦截 `router.push/replace/go`、React `navigate`、Next `router.push/replace` 与 `history/location/window.close` 跳转，使受保护的前端路由可直接访问；`src/core/detector.ts` 对 Vue 亦会清守卫/改 meta。触发有两条路径：点「主动探测」时注入，以及主机进入允许域后的 `document_start` 常驻注册（**此后每次加载自动生效**）。准确的触发条件、无开关特性与客户端边界，以 [功能与模块说明第四节](功能与模块说明.md) 和 [已知限制](已知限制与运行验证.md) 为准。**边界**：仅客户端路由接管，**不绕过服务端鉴权**（受保护接口仍由服务器 401/403 决定能否取数）。

### 2. CrazyEdusrcX / crazy_edusrc — 搜索引擎猎洞
- **Dork 语法库**：教育行业 8 类攻击面、60+ 条，含 `{target_domain}` 占位符。
- **资产测绘四档联动**：Fofa / Quake / 鹰图 Hunter / ZoomEye × 主域 / 证书拓线 / 组件指纹 / 备案主体；外加 crt.name / Wayback / VirusTotal / Shodan / 爱企查 / ICP 等入口。
- **敏感 URL 三级分类**：critical / warn / info，10 类特征。
- **URL 规范化**：搜索引擎跳转还原、去跟踪参数、域名/通配/正则黑名单。
- **导出**：CSV（URL + 等级 + 命中标签）、语法库 JSON 导入导出。
